#  UNIBOT – University FAQ Chatbot

An interactive university chatbot designed to help students access frequently asked questions and university-related information.

##  Project Overview

UNIBOT is a Python-based University FAQ Chatbot developed to simplify access to common university information through an interactive conversational interface.

The system aims to help students find answers to frequently asked questions regarding university services and academic information.

##  Key Features

- Interactive chatbot interface.
- Automated responses to supported university-related questions.
- FAQ-based information retrieval.
- Simple and user-friendly interface.

##  Technologies Used

- Python
- Streamlit

##  Installation and Execution

1. Clone the repository

```bash
git clone https://github.com/mhuka-ryan-03/FAQ-UNIVERSITY-CHATBOT-UNIBOT.git
```

2. Navigate to the project directory

```bash
cd FAQ-UNIVERSITY-CHATBOT-UNIBOT
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```
